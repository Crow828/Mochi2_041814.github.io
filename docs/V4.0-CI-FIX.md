# v 4.0 CI 修复

GitHub Actions 在 Ubuntu 上执行日历验证时，原脚本硬编码了 Windows Edge 路径，导致浏览器启动失败。字卡库等已执行的验证通过，后续步骤由于这个错误被跳过；不能据此认为后续 CI 已全部通过。

本次只修正 tools/verify-calendar-cleanup.cjs 的浏览器查找：优先使用 CHROME_PATH，否则查找 Linux Chrome/Chromium 或 Windows Edge，没有系统浏览器时交给 Playwright 默认配置。网站运行文件、功能和使用数据不变。

验证：本地 Edge 上日历的 360、390、440px 场景通过；实际启动选择逻辑在模拟 Linux 路径、Windows 路径、显式 CHROME_PATH 和默认回退四种条件下均通过。Linux 的完整端到端结果需以补丁上传后的 GitHub Actions 为准。
