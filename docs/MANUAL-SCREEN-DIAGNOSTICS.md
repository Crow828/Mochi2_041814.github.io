# 手动屏幕诊断试用更新

基于本次功能精简版本（用户命名 test 3.6）。

本次仅关闭日常自动屏幕诊断：五秒轮询、窗口/旋转/前后台诊断采集，以及页面 hidden 变化观察器。切页钩子保留为空操作，避免原调用方报错。

设置中的“屏幕适配诊断”仍可手动生成报告。顶部安全区避让、键盘与视口适配、空白页恢复逻辑均保留。未更改聊天数据或功能设置。

已验证：4295 条保留检查、16 条 Service Worker 检查，390/440 像素浏览器下自动诊断定时器为零，连续切页、resize、旋转事件及等待超过五秒后自动屏幕采集为零；手动点击诊断入口能记录 manual 报告。此前切页、滚动、天数和旧数据兼容测试继续通过。

手机实际是否更流畅，仍需本次更新后对比，不能以桌面自动化结果代替 iPhone 真机结论。

## 上传

1. 解压更新包。
2. GitHub Desktop → Repository → Show in Explorer，打开网站仓库。
3. 将更新包内的文件与文件夹全部复制到仓库根目录，同名文件选择替换。
4. **这次不要删除整个 src、js 或 tools 文件夹**，这是局部更新包；其余文件保留。
5. Commit to main，然后 Push origin。Summary 可写“关闭自动屏幕诊断试用”。它是在 test 3.6 之后的独立修改，不覆盖原提交历史。
6. 等待 verify、Pages 部署成功，手机彻底关闭网页应用再打开；不需要清空网站数据。

按之前同样的顺序测试：首页左右滑动、滚动设置、底部桌面/字卡库/设置切换。尽量使用相同壁纸、设置和数据，对比卡顿和点击响应。

## 回退

本次改动在 `src/js/device.js` 的 `AUTO_SCREEN_DIAG` 开关，改回 true 并重新构建可恢复旧自动采集。也可用本次代码备份回退。不要通过删除浏览器数据回退。
