# v4.0 累计更新（2026年10月23日）

## 上传方法

1. 解压更新包，打开内层 mochi2-update 文件夹。
2. 将里面所有文件和文件夹复制到网站仓库根目录，合并文件夹并覆盖同名文件。
3. 在 GitHub Desktop 提交、推送，等待 verify 和 pages build and deployment 完成。

这是 v4.0 之后的累计更新包，包含之前的修复，不需要逐个上传旧补丁。README.md 不包含在包里，避免覆盖你自己的介绍；保留仓库里你修改过的 README。

## 本次收录

- 聊天右上角添加直接拨打语音通话的入口，保留互动菜单里的旧入口。
- 主页朋友圈更换为黑色线框八瓣圆环图标，使用确认后的原尺寸。
- 聊天“更多”图标更换为加号。
- “更多 → 工具”增加按日期查找：选择月份、查看有记录的日期、跳到当天首条记录；兼容互动提示等特殊消息。
- 日期日历打开即显示当前月份；有记录的日期深色显示，当天使用浅灰色圆角底块，不加边框和外投影。
- 修复共用输入弹窗残留其他弹窗提示文字的问题，同步原生与替代输入框。
- 聊天设置增加时间标签字号、互动提示字号，分别保存、可恢复默认，范围 8–24px。
- 包含系统与聊天设置字号、收藏表情尺寸、后台通知自测及 CI 测试初始化等此前修复。

后台通知说明：仍是纯前端网站。这次改善通知自测结果与错误补发，不能保证 iPhone 暂停网页后持续生成消息或发送通知。

更新不包含个人聊天数据，也不会自动清空现有数据。线上版本仍需上传后由 GitHub Actions 验证。
