# 设置界面调整

本包包含本轮设置调整，以及上一轮聊天设置的四组折叠排版。可以在 test 3.7 之后直接覆盖；如果已经安装了聊天设置排版包，也可覆盖。

## 本轮变化

1. 移除设置与聊天设置里的应用全屏模式开关、全屏自动恢复逻辑，以及相应的失效 FAQ/功能搜索入口。历史全屏键不清除，但不再用于自动进入全屏。
2. 各设置组增加左上角小标题，例如“数据备份与恢复”“联系人与群聊”“后台与消息提醒”“隐私与应用锁”。原已有小标题的组继续保留。
3. 寻踪（TA 的日常）与占卜整组移入“通用”，原开关与打开入口继续使用。
4. 应用锁整组从“系统”移到“工具”。密码、启用状态、安全问答、锁屏逻辑没有修改，`applock.js` 原样保留。
5. 设置相关页面里的“功能说明”按钮改为圆形 i，说明内容、键盘操作及原事件保留。按钮仍有完整的无障碍名称。

保留了 iOS 主屏幕应用识别、顶部安全区修复、键盘适配、小游戏共用的面板抬层和边缘保护。没有删除聊天数据、字卡或其他设置。

验证命令：`node tools/verify-release.cjs`；仅检查本轮界面可运行 `node tools/verify-settings-layout.cjs`。

## 上传

1. 解压 `mochi2-settings-ui-update.zip`。
2. GitHub Desktop → Repository → Show in Explorer，打开网站仓库。
3. 将更新包中的全部内容复制到仓库根目录，同名文件选择替换。
4. **这是局部更新包，不要删除整个 src、js、tools 或 .github 文件夹。**
5. Summary 可以写“设置分组与说明按钮调整”，或使用你自己的版本名称，然后 Commit to main → Push origin。
6. 等待 verify 与 Pages 部署通过，手机彻底关闭网页应用再打开。

建议查看：通用里的备份小标题、寻踪/占卜；工具里的应用锁；各标签页的小 i。无需清空网站数据。
