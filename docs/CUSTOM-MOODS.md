# 自定义心情

入口：日历 → 心情日记 → 今天的心情 → 添加心情。
填写一个 emoji 和 1～12 字名称；心情程度默认 3「一般」，用于月度曲线的 1～5 档位置。添加后自动选中新心情，再点「记下今天」记录当天心情。未保存的备注在添加过程中保留。

自定义列表按当前联系人保存，键为 `<activePrefix>:mood-diary-custom`，JSON 数组元素为 `{e:emoji,n:名称,s:程度}`。内置表情和重复的自定义 emoji 不允许再添加；复合 emoji（肤色、连字、旗帜等）按字素检查。名称用 textContent 显示。

原 `mood-diary` 包结构及历史合并保护保留；新记录增加 label/score 快照，使历史记录在自定义列表缺失时仍能显示名称和曲线。TA 心情从内置与当前联系人的自定义列表中独立生成，双方共用表情、名称和程度。选择自己的心情不会强制 TA 跟随；候选列表不变时同一天结果稳定，新增表情会使日期哈希重新映射，历史自动生成的 TA 心情也可能变化。

功能数据目录的 mood 类别包含 mood-diary 和 mood-diary-custom，两者随心情日记导出、导入。通用备份仍按原机制收集键值。没有清理旧日记或其他功能数据。

新增原生 dialog 编辑框，支持取消、Escape 和深色模式；互动卡片弹窗在原生 dialog 打开期间让位。
