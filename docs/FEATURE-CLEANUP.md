## 上传方法

更新包包含完整 `src` 和 `js` 文件夹，不包含浏览器中的个人聊天数据。

1. 解压更新包。
2. GitHub Desktop 选中 `Mochi2_041814.github.io`，点击 Repository → Show in Explorer。核对打开的是 `D:\Github\Mochi2_041814.github.io`。
3. 在仓库外新建备份文件夹，例如 `D:\Teresa Documents\Codex\网站上传前备份`。把仓库现有的 `src`、`js` 两个文件夹剪切到该备份文件夹。不要移动或修改 `.git`。
4. 将更新包里的所有内容复制到仓库根目录。遇到其他同名文件选择替换。此时 `src`、`js` 是整份新目录，旧模块才会真正从 GitHub 删除。
5. 回 GitHub Desktop 查看 Changes：应有新增 `usage-days.js`、`legacy-score-history.js`，并有 garden/room/drift-bottle/cjian 对应旧文件删除。删除清单见 `REMOVED-FILES.json`。
6. Summary 可填“精简功能并保留旧数据”，Commit to main，再 Push origin。
7. Actions 检查本次提交的 verify 和 Pages 部署结果。手机刷新后试用。无需删除主屏幕应用或清空网站数据。

若首次在未提交的 Git 工作树本地构建，旧版防回退检查会提示这些有意删除的检查和重锚；先对照本记录及退役清单，再运行 `node build.mjs --allow-revert`。提交后 CI 的 HEAD 已是本次版本，无需该参数。
