# 聊天设置分组排版

参考页面：https://thori-zhan.github.io/mochi2.0/

本次只调整聊天设置的排版，沿用当前配色。基于 test 3.7，继续保留之前的功能精简、顶部修复和关闭自动屏幕诊断。

## 新排版

- 名称与头像：联系人/我的聊天昵称及头像，默认展开。
- 显示与阅读：边看边调、聊天美化方案、壁纸、字体、气泡、显示相关设置，默认展开。
- 输入与操作：发送方式、批量发送、语音、输入按钮排序、消息操作，默认收起。
- 数据与更多：聊天记录导入、导出与删除入口，默认收起。

静态长说明收进小 i 按钮，点击后显示完整说明。删除、导入等原入口及其确认逻辑保留，没有自动执行数据操作。条件隐藏项（例如没有头像时的“清空头像”）继续按原条件显示。

没有复制朋友网站的全部界面或全站配色，也没有改首页、字卡库、联系人数据或聊天记录。

## 实现与验证

新增 `src/js/chat-settings-layout.js` 和 `src/css/chat-settings-layout.css`。移动原有设置节点，保留控件 ID、事件绑定和存储键。原标签页作为内部跳转兼容锚保留，界面不再显示。

`node tools/verify-chat-layout.cjs` 检查 360、390、440 像素宽度：

- 设置节点和所有原 ID 没有丢失或替换；每行条件隐藏状态保持。
- 四个分组、默认展开状态、滚动与深色模式。
- i 按钮打开说明而不误触头像上传。
- 原开关仍可保存、昵称编辑仍可打开。
- 边看边调可打开，并返回“显示与阅读”。
- 导入、导出、删除入口完整；测试不执行删除和导入。

`node tools/verify-release.cjs` 包含构建、原有二改验证和新排版验证。GitHub Actions 增加了聊天设置排版验证步骤。

这是浏览器自动化和截图检查结果；iPhone 真机仍需上传后查看。

## 上传

1. 解压 `mochi2-chat-settings-layout-update.zip`。
2. GitHub Desktop → Repository → Show in Explorer，确认打开网站仓库。
3. 将更新包内的全部文件和文件夹复制到仓库根目录；同名文件选择替换。
4. **这是局部更新包，不要删除整个 src、js、tools 或 .github 文件夹。**
5. GitHub Desktop 的 Summary 可写 `test 3.8`，也可自行命名。Commit to main，再 Push origin。
6. 等待本次 verify 和 Pages 部署成功，手机关闭网页应用后重新打开。
7. 进入聊天 → 聊天设置，检查四个分组、小 i 说明和你常用的开关。不需要清空浏览器数据。

若返回旧版，用本次修改前的代码备份恢复并重新构建即可，不需要恢复手机聊天数据。
