# 聊天多选与收藏备注

点击聊天气泡，在操作菜单选「多选」，勾选双方消息后点「保存收藏」。一条沿用原单条收藏；两条以上保存为一个聊天组合，按聊天顺序显示双方气泡，独立外框、数量标题和备注入口。取消、Escape、离开聊天或切换联系人都会退出选择。

组合仍使用当前联系人的 fav-msgs 数据包，kind 为 msg，type 为 chat-group，带唯一 id 和 items 消息快照。保留每条原时间、方向、文本、媒体 parts 和 mood。原有收藏不迁移、不清理。原收藏筛选、统计、导入导出及批量管理仍作用于整个组合；组合计作一项收藏。媒体压缩和令牌化递归处理 items，并保留原有写盘保护。

每个收藏条目（包括已有聊天、互动、信件、朋友圈和 TA 收藏）均可填写最多 500 字备注，保存于条目 note；留空可清除。组合的备注针对整个组合。备注以纯文字显示，编辑时检查联系人和读取状态，避免串联系人或未读完整时写入。

勾选使用原消息渲染身份 data-mk，不用可变化的数组下标。新消息和列表重绘不会让已选消息串条，保存前按当前聊天顺序重新定位；已不存在的消息不保存。选择期间只监听列表变动更新勾选，不改聊天内容。

单条与组合收藏均使用统一外框，消息快照中的情绪、心意、多字卡回复等放入独立 msg-moods 容器，排在正文下方并允许长标签换行。每个外框末尾右对齐显示完整日期与时间。新收藏增加 collectedAt，保留原 ts 作为消息时间，备注修改和重新打开不重写收藏时间；旧条目没有 collectedAt 时注明「原记录时间」，不推测收藏日期。

每个外框有类型标题：聊天记录、互动卡片、信件、朋友圈；组合标题保留条数。信件正文前显示发送者姓名和原信时间，新增 senderRole/senderName 快照，旧来信根据原 mailType 和当前信箱姓名回退。

朋友圈收藏保存 sourceId、authorRole、authorOwner、authorName、authorAv、side；收藏者 by 与动态作者分别记录。旧收藏在显示时按动态 ID 或时间加全文唯一匹配作者，不改写旧数据；无法匹配时使用已有方向信息，完全无依据则标为「作者信息未记录」。一次渲染只读取和建立一次动态索引，避免每条收藏重新解析朋友圈数据。朋友圈头像不参与聊天头像的全局刷新，以免其他联系人或旧快照被当前聊天头像覆盖。TA 自动收藏我的动态也保存同样的作者快照及 collectedAt。

批量管理的圆圈统一置于每个外框内容上方并居中，不再根据原消息方向决定插在顶部还是底部。朋友圈内层删除重复的「朋友圈动态」标签。信件采用与信箱详情相同的 mail-paper 结构，姓名和原信日期在顶栏、标题独立加粗、正文保持换行与行距；不再将标题塞入灰色小标签。发送者回退不使用默认桌面名称，旧快照中的「默认/default」也不作为人名显示；无有效名称时来信显示 TA，回信仍显示我方姓名。
