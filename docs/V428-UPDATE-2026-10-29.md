# v4.2.8 更新与安装说明

- 新增奶白淡粉、奶白酒红、暖米杏三款配色，补齐多处按钮、选中状态及概率滑条的主题色。

- 设置 → 通用 → 更新说明已收录本次更新，开屏版本显示同步为 v4.2.8。

## 安装

1. 解压更新包，打开 mochi2-fix 文件夹。
2. 将其中全部内容复制到现有仓库根目录，合并文件夹并替换同名文件，包含 tools 与 .github 中的验证文件。不要将整个 mochi2-fix 文件夹套在仓库外面。
3. 在 GitHub Desktop 检查改动后提交并推送，等待 Actions 与网页部署完成。
4. 手机收到新版本提示后点击刷新更新；在版本检查中确认显示 v4.2.8。

本包不包含 README.md，保留你的 README；不包含个人聊天、字卡或健康记录。更新时不需要导入旧备份。建议更新前按平时习惯导出一份当前数据备份。
