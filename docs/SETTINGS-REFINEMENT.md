# 设置细节与遗留项清理

本更新包含此前的聊天设置分组、主设置分类、灰色框内小标题、开关对齐及工具排序。

## 本次调整

1. 通用：跨桌面查岗频率的 i 放在标题行最右侧，与其他说明入口对齐。
2. 通用：深色模式使用相同的滑动开关。点击开关直接切换深浅；点击行内文字仍可选择浅色、深色、跟随系统，已有主题设定兼容保留。
3. 回复设置 → 聊天 → 字卡与概率：9 个停用功能的概率放入原框内的「已停用的字卡概率」折叠区，默认收起。存钱罐仍在运行，保持在折叠区外。移动现有行，保留原 ID、概率值、禁止修改的保护与说明。
4. 回复设置 → 信箱：移除每周摸鱼小结开关、生成函数与调度调用；普通主动来信和回信流程保留。已收到的旧小结不删除。
5. 查岗：标题改为「TA主动查岗与概率」。
6. 回复设置 → 其他：标题改为「TA主动邀请」。
7. 同一邀请框内增加「猜拳」「玩游戏」「贴贴」「分享你的字卡」小标题，各自下面仍是原开关和概率控件。
8. 移除摸鱼值、工作值和摸鱼抓包浮字的遗留设置行、默认配置和绑定。代码搜索确认实际加分引擎已在前次清理移除；一起使用天数走独立 usage-days 模块，旧积分只读记录走 legacy-score-history 模块，两者保持。旧存储键、记录不清除。
9. 粉红条属于后台通知权限提示。原 .gs-sub 的 display:block 规则盖过 hidden，导致没有文字时也出现空条。现在遵守 hidden，无内容时不显示；存在权限问题时保留原动态提示。该提示放在后台通知说明后，避免误认为属于通知逐条弹。
10. 离线消息提醒下的灰字属于该功能的设备支持、权限和注册状态。增加「离线消息提醒状态」标签、独立浅灰说明区，并通过 aria-describedby 与开关关联。
