# v4.2.7 更新与验证说明

日期：2026年10月26日

## 更新内容

1. 心情日记在添加心情旁增加管理心情入口。可修改自定义 emoji、名称和程度，或删除自定义选项，删除前需确认。
2. 管理操作不改写已保存的日记。已有名称、分值、备注和日期保持原记录；删除选项不会删除历史日记。
3. 默认聊天底栏顺序调整为：更多、输入框、表情包、照片、语音、发送。继续说和批量发送仍由原有开关控制；语音位于发送左侧，表情包位于照片左侧。
4. 手动保存过的自定义顺序继续保留，可在聊天设置的输入栏按钮位置中恢复默认排列。聊天与群聊仍共用原来的排序机制，所有按钮保持原有节点和功能绑定。
5. 开屏当前版本、version.json、构建信息及设置更新说明同步为 v4.2.7。更新说明新增2026年10月26日条目，旧说明保留。
