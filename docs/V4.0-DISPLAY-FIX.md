# v4.0 字号与收藏表情修复

解压补丁后，将里面的文件和文件夹复制到网站仓库根目录，合并文件夹并覆盖同名文件，然后提交、推送。不要把补丁外层文件夹整体放入仓库。保留现有其他文件。

- 设置内 gs-row 选项与其他设置行共用「14px + 文字大小微调」规则，修复设备启用文字微调后系统与其他分类字号不一致的问题。
- 聊天设置正文放大至 14px，右侧数值调整为 12.5px，360px 屏幕不再单独缩小正文。
- 信件收藏内嵌表情按原比例限制在 100px 内。
- 兼容旧聊天记录中缺少 sub 类型的表情，避免作为 260px 照片显示；表情缩略图限制在 96px 内，明确标记的普通照片保留照片展示方式。

验证：360、390、440px 的收藏身份、信件、组合/单条高分辨率表情、照片类型及字号检查；文字大小微调 -2、+2、+4px 时所有系统行与聊天分类逐项比对；设置布局与聊天设置交互检查。测试使用独立浏览器数据，不修改用户数据。
