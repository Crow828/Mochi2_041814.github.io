# test3.6：第一轮交互性能调整

基线：GitHub test 3.5 / 6156a89。本包尚未提交或上传，建议下一次提交名 test3.6。

改动：
- 默认未配置音效时，普通点击不再创建 Web Audio 引擎；配置音效后仍在用户手势内解锁，播放和铃声逻辑不变。
- 桌面编辑布局专用的非 passive 触摸拦截器，仅在编辑模式注册，退出时移除。
- 桌面图层预热随滚动延长，滑动停止后释放，不再仅起手150ms后就撤销。
- 重复点击当前底部标签不再隐藏/重开同一页面（仍可收起输入法）。
- 页面导航栏同步观察器合并批处理；字卡库首页计数/回填放到页面有绘制机会之后，快速切走时取消尚未开始的旧任务。
- 非编辑状态切底部栏时跳过拖拽模式的重复全页面清理。

验证：4387/4387 构建检查、16/16 SW 检查通过；390/440px 下静音/配置音效初始化、字卡计数、快速切页、同页重复点击、编辑模式与普通滚动、设置纵向滚动、原有功能开关测试均通过。测试使用独立浏览器上下文，没有操作日常网站数据。

测量边界：本机 Chromium 4倍 CPU 降速，回调计时定位出首次点击中音频初始化约195ms的样本。调整后一次相同场景首击同步处理约32ms，普通后续点击约11~17ms。采样次数有限、环境存在波动，不能当成稳定提速比例，更不能当成 iPhone 真机结果。设置页首次显示到两个动画帧的样本仍约308ms，没有被本轮消除。设置滚动的 iOS 掉帧也尚未在本机复现；本包是试用优化版，不代表所有卡顿已修复。

上传：将压缩包解压后的内部文件合并到 GitHub Desktop 的 Repository → Show in Explorer 打开的仓库目录，替换同名文件，保留其他文件。Summary 建议 test3.6，然后 Commit to main → Push origin。等待 Actions 与 Pages 部署。真机需复查首次进入字卡库/设置、反复切换三个底部标签、桌面横滑、设置纵滑，以及已配置的消息音效/来电铃声。无需删除浏览器数据。

README、署名、原有数据字段及已验证的 iPhone 顶部适配未改。备份保存在当前聊天工作目录 work/before-scroll-optimization、work/before-tab-optimization、work/before-audio-optimization。
