# v4.2.9 补丁1：延迟聚焦修复

截图中的断言失败可稳定复现，并非仅验证脚本误报：打开提问卡片时排定的延迟聚焦，在用户切到聊天输入框后仍可能执行，使焦点被抢回没有 id 的回答输入框。

修复：记录新的聚焦与点击操作；延迟回调只有在期间没有新的操作、联系人未切换、输入框仍在当前聊天页时才执行。输入框已经聚焦时不重复聚焦。恢复草稿的另一条延迟回调也使用同样的保护。

验证保留原断言，并将切换操作放在同一任务内，保证测试能覆盖延迟回调尚未执行的场景。原版构建在此测试中失败；修复后 Chromium、WebKit 在360、390、440px下通过；主聊天输入、组合输入回车、输入法重新唤起和版本弹窗焦点另行验证。

将包内 `mochi2-fix` 的内容合并替换到现有 v4.2.9 仓库根目录，提交推送后等待 Actions 和网页部署完成。手机刷新后，开屏显示 **v4.2.9 补丁1**。更新说明中也增加了本次修复。

不需要导入备份或清理网站数据。本补丁不包含 README.md。
